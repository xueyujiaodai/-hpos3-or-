侧边栏场景切换机制（示意）

手机管家 12.1.3-251205.0.1 · HyperOS 3 · 关键规则：切换必须先取消当前场景，再进入目标场景

视频场景 游戏场景 存储层 进程内广播
① 场景判定：前台应用 × 应用名单
当前前台应用
E.e() 前台信息
→
视频名单查询
pref_video_box_app_list 含 pkg？
游戏名单查询
gamebooster provider 含 pkg？
命中视频名单 → 视频场景
VideoToolBoxService 拉起视频工具箱 I3.w.m()
命中游戏名单 → 游戏场景
GameBoosterService 拉起游戏工具箱 I.B.e0()
② 视频场景 → 游戏场景（核心诉求）
第一步：先取消视频场景（①–④） 第二步：再切换游戏场景（⑤–⑥）
① 退出视频工具箱
I3.w.e(ctx).n()：清 boosting 标志、隐藏窗口
② 从视频名单移除 pkg
pref_video_box_app_list 写入新名单
③ 加入视频删除名单
pref_video_box_app_del_list 防默认名单回填
④ 广播通知视频服务重载
gb.action.update_video_list（进程内广播）
⑤ 写入游戏名单
gamebooster provider 插入 flag_white=0 行，并清除手动删除标记
⑥ 拉起游戏工具箱
gb.action.update_game_list + I.B().R(pkg)/a0(uid)/e0()
执行顺序严格为 ①→②→③→④→⑤→⑥：不先退出视频工具箱，两个场景会同时挂屏、下次前台变化还会再次拉起视频工具箱。
③ 游戏场景 → 视频场景（对称，同样先取消再切换）
① 退出游戏模式
I.B().g0()
② 游戏名单删除
provider 删除 + 手动删除标记
③ 广播重载
gb.action.update_game_list
④ 加入视频名单
pref_video_box_app_list + 清删除标记
⑤ 拉起视频工具箱
gb.action.update_video_list + I3.w.m()
④ 存储层（名单与开关落在哪里）

· pref_video_box_app_del_list（删除名单）

content://com.miui.securitycenter.gamebooster/gamebooster
· 每个游戏一行（app_name / package_name / package_uid / flag_white=0 / 各项 settings_*）
Settings.Secure
· pref_videobox_switch_status（视频总开关）
· pref_open_game_booster（游戏总开关）
· gb_boosting / vtb_boosting（场景驻留标志）
名单变更通知走进程内广播（发送器为混淆类 P.a，即包 P 下的类 a）；模块注入 remote 子进程后可直接复用该通道，也可回退 androidx LocalBroadcastManager。
